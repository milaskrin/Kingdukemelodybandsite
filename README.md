# King Duke Melody Band of Africa

Static website bundle for VS Code.

## Files

- `index.html` is the website page.
- `styles.css` contains layout, responsive styling, and visual theme.
- `script.js` controls the mobile navigation and current footer year.
- `assets/` contains the supplied logo, portraits, promotional art, and shoe photos.

## Launch

Open `index.html` in a browser, or open the folder in VS Code and use the Live Server extension. Spotify players and Google Fonts need an internet connection; the rest of the page is local.

Product enquiries use `kingdukemelodybandofafrica@gmail.com`. The music section embeds the supplied Spotify tracks; it does not host or download the audio files.
